# Code of Conduct

## Our Standard

We expect contributors and maintainers to interact professionally and respectfully.

Examples of expected behavior:

- being respectful in technical disagreement
- giving actionable, specific feedback
- focusing critique on code and behavior, not people
- assuming good intent while still being precise

Examples of unacceptable behavior:

- harassment or personal attacks
- discriminatory language or behavior
- doxxing or publication of private information
- repeated bad-faith disruption of technical discussion

## Enforcement

Project maintainers may remove comments, reject contributions, or block participation for behavior that violates this code of conduct.

## Reporting

Report serious issues through the security or maintainer contact path described in `SECURITY.md`.

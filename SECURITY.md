# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public issues.

Instead, disclose them privately to the project maintainers through the repository security contact path once the GitHub repository is configured.

When reporting, include:

- affected version or commit
- impact summary
- reproduction steps
- any proof-of-concept details needed to validate the issue

We will validate the report, assess impact, and coordinate remediation before public disclosure when appropriate.
